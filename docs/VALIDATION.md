# v0.2.0 验证范围

- 原图预设来自本机正在使用的原壁纸插件配置，保留背景 ID、玻璃、边框、圆角、字体开关、挂件及画面参数。
- 仓库预览为在独立浏览器会话中重新截取的真实 DSH Web 首页，未使用用户上传的截图。只在截图会话的 DOM 中移除了个人会话列表，未改写页面布局、背景或组件样式。
- 客户端没有全局 CSS，没有独立视频层，没有给原生侧栏、输入框或卡片增加容器。
- 自动测试覆盖精确参数应用、缺少视频时拒绝写入、失败回滚、保留后续手调参数、备份写入权限以及 v0.1 客户端清理。
- 独立浏览器加载实际 DSH 页面验证：注册本插件前后原生侧栏、输入卡片的几何尺寸一致，样式标签与视频数量不变。
- 新预览为 1600 × 1000 PNG；捕获时原生输入框存在、原视频正常解码，捕获前后原壁纸插件配置文件字节一致。
- 仅在隔离的测试请求中验证应用/恢复事务，不把测试配置写入用户正在使用的壁纸设置。

同一版本、主题、参数、窗口与缩放下由同一原插件渲染。动态视频的帧差异，以及不同宿主/缩放造成的位置差异，不属于配置可消除的差异。
