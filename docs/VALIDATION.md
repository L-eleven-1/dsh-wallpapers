# 验证记录

版本：0.1.0。验证日期：2026-10-24。

## 已验证

- 5 项 Node.js 自动测试通过：设置校验、视频 Range、Steam 本地目录发现、HTTP 读写权限与宿主卸载。
- 在实际 DSH Desktop 0.12.1 后端提供的页面中，以独立 Edge 浏览器会话加载本插件客户端。
- 本机“奶皇新”视频读取成功，浏览器获取到视频尺寸并解码；默认静音。
- 启用、停用、再次启用均可工作；卸载测试清除了背景节点、样式、定时器和事件监听。
- 预览图使用虚构的会话/插件内容，不包含个人会话或密钥。

## 验证范围

未把这个开发版本安装到用户当前正在使用的 DSH profile，也没有重启 DSH 或操作系统。插件市场安装后的原生设置分区，使用的是已检查的 DSH `settings.section` 槽位；仍可能受未来宿主接口变动影响。

本仓库未包含 Wallpaper Engine 视频文件。其他机器需先获取本地视频；自动发现不适用于非默认 Steam 安装位置时，可手动指定完整视频路径。
